GCal iOS URL Scheme Tests

Tap each button and note what happens. Does GCal open? Does it create an event?

1. Just open the app

comgooglecalendar://

2. With /render path + TEMPLATE params

comgooglecalendar://calendar/render?action=TEMPLATE&text=Test+Event&dates=20260823T180000/20260823T210000

3. With /event path + TEMPLATE params

comgooglecalendar://calendar/event?action=TEMPLATE&text=Test+Event&dates=...

4. With /r/eventedit path

comgooglecalendar://calendar/r/eventedit?text=Test+Event&dates=...

5. With /eventedit path (no /r/)

comgooglecalendar://eventedit?text=Test+Event&dates=...

6. With /new path (like Outlook scheme)

comgooglecalendar://new?title=Test+Event&start=2026-08-23T18:00:00&end=2026-08-23T21:00:00

7. With /event/new path

comgooglecalendar://event/new?title=Test+Event&start=...

8. googlecalendar:// (alternate scheme)

googlecalendar://

9. Full web URL passed after scheme

comgooglecalendar://calendar.google.com/calendar/render?action=TEMPLATE&text=...

10. With action=create

comgooglecalendar://event?action=create&text=Test+Event&dates=...
