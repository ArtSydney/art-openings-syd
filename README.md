# Art Openings Sydney

Every exhibition and opening happening in Sydney, updated daily.


## Features

- List view with search, suburb filter, opening filter
- Calendar view (month grid + mobile agenda)
- ICS download per exhibition + bulk ZIP export
- Google Calendar deep-link
- Discord notifications: new exhibitions, opening-soon, closing-soon alerts
- Automatic status management (active/closed sweep)
- Deduplication across all sources
